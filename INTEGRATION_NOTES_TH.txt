HWK Stock Combined

เมนูแรกของโปรแกรม
1. เตรียมข้อมูล -> CountStock
2. นับสต๊อก -> HWK Stock เดิม
3. ออก

หลักการแยกโปรแกรม
- HWK Stock ใช้ database และ config เดิม
- CountStock ใช้ countstock/countstock_inventory.db แยกต่างหาก
- หน้า Config ของ CountStock เลือกสาขาจาก get_config.ashx
- ข้อมูล DB/เดือน/User/Password อ่านจาก config.ashx ไม่ให้กรอกเอง
- Logic ภายใน screens/services/repository เดิมของ HWK Stock ไม่ถูกแก้ไข

พฤติกรรมหน้าเก็บรายการ CountStock
- ผู้เก็บข้อมูลกรอกเอง
- Location รับค่าใดก็ได้ ไม่ตรวจ master
- Barcode ค้นก่อน ถ้าไม่พบค้น Product Code
- Enter จากเครื่องสแกนจะบันทึกอัตโนมัติ
- รายการเดิม Location + Product + ค่าที่สแกน จะบวก Qty +1
- หลังสแกนหรือเปลี่ยน Location จะคืน Cursor ไปช่อง Barcode
- ไม่มีปุ่ม Save ในหน้าเก็บรายการ
